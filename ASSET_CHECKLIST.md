## Image Naming Convention

Use descriptive, lowercase names with hyphens:

```
hero-team.jpg
about-office.jpg
tally-dashboard.jpg
client-august-consulting.png
partner-microsoft.png
og-image.jpg
```

## Image Optimization Checklist

Before uploading:
- [ ] Compress images (use tools like TinyPNG, Squoosh)
- [ ] Convert to WebP or AVIF where possible
- [ ] Provide appropriate dimensions (don't upload 4000px images)
- [ ] Ensure file sizes are under 500KB (ideally under 200KB)
- [ ] Use descriptive alt text for accessibility
